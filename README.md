# renantatsuo.dev

Personal blog and portfolio website built with TanStack Start.

## Development

```bash
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Build

```bash
bun run build
```

## Type Checking

```bash
bun run type-check
```

## Deploy

The site is deployed on Vercel. The build process generates a static site with server-side rendering support.
